# Interface references

Requested by the owner: Melvor Idle, Melvor Idle 2 and Idle Clans. Reviewed the public Melvor guide and official/publisher screenshots to study compact skill navigation, resource quantities, activity selection and recipe panels. Our implementation uses the original Creature Adventure content and artwork with code-native panels/icons.

- https://wiki.melvoridle.com/index.php?title=Beginners_Guide
- https://store.steampowered.com/app/3218350/Melvor_Idle_2/
- https://news.melvoridle.com/melvor-idle-2-development-progress-update-september-2026/
- https://store.steampowered.com/app/2103530/Idle_Clans/

The desktop layout groups skills with current levels, shows an activity catalog beside the selected recipe and retains the animated team arena. Mobile keeps a compact menu, direct skill strip and bottom navigation. Bank uses count-based stack grids.
